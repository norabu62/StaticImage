To open the interface, type `/si`

Place images in any folder inside the `Interface` folder (you can also use any existing in-game texture).

Important: images must be **.tga** (or .blp) format, with each side a **power of two up to 1024** — e.g. 256x256, 512x512, 512x1024. Use 32-bit TGA for transparency. In the texture-path box, leave off the file extension.
